多邮箱未读提醒，安静又干净

Mail Notifier 在浏览器工具栏集中显示 163 / QQ / USTC 邮箱 / Gmail 的未读邮件数量， 并在新邮件到达时弹出桌面通知。全程在本机完成，不向任何第三方服务器上传邮件数据。

核心特性

📮

多邮箱统一面板

一处查看 163、QQ、中科大（USTC）、Gmail 的未读数与最新状态。

🔢

工具栏角标

各邮箱未读数一目了然，新邮件即时点亮角标。

🔔

桌面通知

有新邮件时静默弹出本地通知，不打扰您当前工作。

🤫

完全静默后台检查

定时在后台运行，绝不自动打开或常驻任何邮箱标签页。

🧠

智能会话学习

偶尔打开一次邮箱即可学习真实接口格式并缓存会话，之后无需开着邮箱页面也能纯后台读取未读数（会话缓存 7 天）。

🔒

隐私优先

全部数据仅保存在本机浏览器（chrome.storage.local），无服务器、无账号、不上传邮件内容；Gmail 走隐藏 Atom feed + 浏览器会话 Cookie（零 token、无需 Google Cloud OAuth 商业授权）。

检查间隔可自定义

检查间隔（1–30 分钟）与检查模式（混合 / 仅内容脚本 / 仅 SW API）均可自定义，适配不同使用习惯。

快速开始

  1. 在浏览器中登录需要监控的邮箱（163 / QQ / USTC / Gmail）。
  2. 安装扩展后打开设置页，点击「🔑 授权 · 同步会话」以提取并缓存会话。
  3. 回到日常使用：扩展每 N 分钟在后台静默检查，通过角标与桌面通知提醒新邮件。
  4. 若会话过期，扩展会提示「需手动同步」，不会擅自打开页面打扰您。
设计承诺：自动检查不会打开任何标签页，也不会常驻邮箱页面。 仅当您在扩展界面主动点击时，才可能打开邮箱页同步会话。

常见问题

需要注册账号或服务器吗？

不需要。扩展不运营任何服务器，也不收集账号，所有数据保存在您本机。

为什么需要 Cookie 权限？

仅用于向您已登录的 webmail 发起本机请求以读取未读数，Cookie 不会外传，详见 隐私政策。

可以只用 Gmail 吗？

可以。Gmail 通过隐藏 Atom feed（mail.google.com/mail/u/0/feed/atom）读取未读， 依赖浏览器已登录 Gmail 的会话 Cookie，无需其他邮箱配置。
