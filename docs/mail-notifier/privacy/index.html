隐私政策 · Privacy Policy

适用于浏览器扩展 Mail Notifier（MV3）· 生效日期：2025-01-01 · 最近更新：2025-01-01

1. 简介

Mail Notifier 是一款邮件未读提醒扩展，支持 163 / QQ / USTC / Gmail 邮箱。 其设计核心为纯本地处理、无服务器、自动运行完全静默：扩展在您的本机浏览器中完成所有邮件状态检查与提醒， 不上传您的邮箱数据到任何第三方服务器。

2. 我们收集哪些信息

扩展仅在您于本机浏览器登录上述邮箱并授权的情况下，读取完成邮件提醒所必需的最小数据：

  • 邮箱账户的会话状态（sid）与未读计数：用于向 webmail 查询是否有新邮件并展示角标 / 发送桌面通知；
  • Gmail 账户数据：经 Google 官方 REST API 以只读权限（gmail.readonly）读取未读邮件元数据；
  • 浏览器 Cookies（会话 Cookie）：仅用于向您已登录的 webmail 发出本机请求以获取未读数。

我们不读取、收集、存储您的邮件正文内容用于任何分析；仅使用未读元数据。

3. 数据如何存储与使用

  • 所有数据（sid、未读状态、API 模式等）仅保存在您的本机浏览器 chrome.storage.local 中；
  • 检查逻辑全部在本机 Service Worker 内执行；
  • 我们不拥有、不运营任何服务器，数据不传输、不共享、不出售、不用于广告或画像。

4. 自动运行与隐私

  • 定时自动检查在后台静默执行，绝不自动打开新标签页、不常驻页面；
  • 仅当您在 Popup / 设置页主动点击时，才可能打开邮箱页以同步会话；
  • 若后台无法取得数据，只会提示「需手动同步」，不会越权访问您的其他数据。

5. 第三方（Google）数据处理

本扩展使用 Google 官方 OAuth2 流程与 Gmail REST API，仅申请 gmail.readonly（只读）权限。 Gmail 数据的使用遵循 Google API Services User Data Policy（含 Limited Use 有限使用要求）。

  • 仅用于提供用户可见功能：读取未读邮件数量与必要的元数据（发件人、主题、时间）， 用于在工具栏角标与桌面通知中展示未读提醒；
  • 不传输给第三方：数据仅在本机浏览器内使用，不会传输给任何第三方服务器、广告平台或数据经纪商；
  • 不用于广告、画像或信用评估：不使用 Gmail 数据投放广告、建立用户画像或进行借贷/信用评估；
  • 不用于训练 AI 模型：不使用您的 Gmail 数据训练或改进任何通用/第三方 AI 模型；
  • 人类不可读：我们不允许人工（开发者本人或第三方）读取您的 Gmail 数据， 除非您明确请求支持、为安全目的调查滥用，或法律要求；
  • 数据保留与删除：Gmail 相关令牌与未读状态保存在本机 chrome.storage.local，可随时在扩展设置页清除；卸载扩展即全部删除。

6. 数据共享与披露

我们不会向任何第三方出售、出租或共享您的数据，除非：

  • 为遵守法律 / 监管 / 司法要求而必须披露；
  • 为保护我们的权利或防止滥用。

7. 数据保留与删除

  • 扩展卸载后，其存储在您本机浏览器中的数据即随之清除；
  • 您也可以随时在扩展的 Popup / 设置页手动清除缓存的会话数据。

8. 权限用途说明

9. 安全

扩展使用 chrome.storage.local 在受隔离的浏览器扩展沙箱中保存数据，并遵循 MV3 最小权限原则。 因数据始终保存在本机，安全风险主要来自您本机环境本身。

10. 政策更新

本政策可能随功能演进更新。更新后将在扩展的商店列表说明中提示，重大变更会在新版本 release note 中说明。

1. Introduction

Mail Notifier is an unread-email notification extension supporting 163 / QQ / USTC / Gmail mailboxes. It is designed around purely local processing, no servers, and fully silent automatic checks: all mailbox status checks and notifications happen in your local browser, and your mailbox data is never uploaded to any third-party server.

2. Information We Access

Only when you are signed in to the above mailboxes in your local browser and have granted authorization does the extension read the minimum data required for notifications:

  • Mailbox session state (sid) and unread counts — used to query webmail for new mail and to render the badge / send desktop notifications;
  • Gmail account data — read-only unread message metadata via the official Google REST API (gmail.readonly);
  • Browser cookies (session cookies) — used solely to send local requests to webmail sites where you are already signed in.

We do not read, collect, or store your email message bodies for any analysis; only unread metadata is used.

3. How Data Is Stored and Used

  • All data (sid, unread state, API patterns, etc.) is stored only in your local browser's chrome.storage.local;
  • All checking logic runs inside the local Service Worker;
  • We do not own or operate any server. Data is never transmitted, shared, sold, or used for advertising or profiling.

4. Automatic Operation and Privacy

  • Scheduled background checks run silently and never open a new tab or keep a page resident;
  • Only when you explicitly click in the Popup / Settings page may a mailbox page be opened to sync the session;
  • If background checks cannot obtain data, the extension only shows a "manual sync required" hint and never accesses other data beyond its scope.

5. Third-Party (Google) Data Processing

The Extension uses the official Google OAuth2 flow and the Gmail REST API, requesting only the gmail.readonly scope. Use of Gmail data complies with the Google API Services User Data Policy, including the Limited Use requirements.

  • User-facing functionality only: unread counts and minimal metadata (sender, subject, time) are used solely to show badges and desktop notifications;
  • No transfer to third parties: data stays in your local browser and is never sent to third-party servers, ad platforms or data brokers;
  • No ads, profiling or credit assessment: Gmail data is not used for advertising, profiling, or lending/credit decisions;
  • No AI model training: your Gmail data is never used to train or improve AI models;
  • No human reading: no humans (developers or third parties) read your Gmail data except with your explicit request for support, for security investigations, or as required by law;
  • Retention and deletion: Gmail tokens and unread state are stored locally in chrome.storage.local, can be cleared from the extension settings at any time, and are removed when the Extension is uninstalled.
  • Gmail data handling follows the Google APIs Terms of Service and the Google Privacy Policy;
  • Gmail data is never used for purposes beyond Google's limited-use requirements.

    • 6. Data Sharing and Disclosure

    We do not sell, rent, or share your data with any third party, except:

    • when disclosure is required to comply with legal, regulatory, or judicial requirements;
    • to protect our rights or prevent abuse.

    7. Data Retention and Deletion

    • Uninstalling the extension removes the data stored in your local browser;
    • You may also clear cached session data at any time from the extension's Popup / Settings page.

    8. Permission Usage

    Permission Purpose
    cookies Attach session cookies to local webmail requests to read unread counts
    storage Store sid / unread state / API patterns locally

    notifications Show desktop notifications for new mail
    tabs Only to detect and reuse mailbox tabs you already have open (never opens tabs automatically)
    identity Gmail OAuth2 authorization (read-only)
    scripting / declarativeNetRequest Inject scripts / network rules that support the hybrid checking strategy

    9. Security

    The extension stores data in the isolated browser extension sandbox via chrome.storage.local and follows MV3 least-privilege principles. Because data always stays on your device, security risks mainly come from your local environment.
