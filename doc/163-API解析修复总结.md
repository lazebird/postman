# 163 API 解析修复总结

## 问题
163 邮箱 SW API 请求成功（status=200），但解析失败。

## 根因
163 API 响应使用**非标准 JSON 格式**：
1. 使用单引号而非双引号：`'code':'S_OK'`
2. 日期格式非标准：`new Date(2007,11,9,6,57,3)`
3. 布尔值未加引号：`'read':true`

## 解决方案
使用**正则表达式**直接解析响应，避免 JSON.parse：

```javascript
// 匹配每封邮件对象
const emailRegex = /\{\s*'id'\s*:/g;

// 统计未读邮件（没有 read:true 的）
while ((emailMatch = emailRegex.exec(jsonText)) !== null) {
  const hasRead = /'read'\s*:\s*true/.test(emailText);
  if (!hasRead) unreadCount++;
}
```
