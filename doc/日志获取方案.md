/**
 * 日志获取方案说明
 * 
 * ## 方案 1: 通过 chrome.storage.session 获取（推荐）
 * 
 * 扩展已实现日志持久化到 chrome.storage.session，可以通过以下方式获取：
 * 
 * ### 方式 A: Popup 日志标签页
 * - 打开扩展 Popup
 * - 点击「日志」标签
 * - 查看实时日志
 * 
 * ### 方式 B: 通过 sendMessage API
 * ```javascript
 * chrome.runtime.sendMessage({ type: 'getDebugLogs', limit: 100 }, (response) => {
 *   console.log(response.logs);
 * });
 * ```
 * 
 * ### 方式 C: 通过 Content Script 中转
 * 在邮箱页面注入 content script，通过 chrome.runtime.sendMessage 获取日志
 * 
 * ## 方案 2: 通过 Console API 获取
 * 
 * 打开 `edge://extensions/` → 找到扩展 → 点击「Service Worker」
 * 在控制台执行：
 * ```javascript
 * // 获取内存中的日志
 * chrome.runtime.sendMessage({ type: 'getMemoryLogs', limit: 100 });
 * ```
 * 
 * ## 方案 3: 导出日志到文件
 * 
 * 在 Service Worker 控制台执行：
 * ```javascript
 * chrome.storage.session.get('debugLogs', (data) => {
 *   const logs = data.debugLogs || [];
 *   const blob = new Blob([JSON.stringify(logs, null, 2)], { type: 'application/json' });
 *   const url = URL.createObjectURL(blob);
 *   const a = document.createElement('a');
 *   a.href = url;
 *   a.download = `mail-notifier-logs-${Date.now()}.json`;
 *   a.click();
 * });
 * ```
 * 
 * ## 自动化获取（推荐）
 * 
 * 创建一个简单的 HTTP 服务器，暴露日志接口：
 * 
 * ```javascript
 * // 在 popup.js 中添加
 * chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
 *   if (message.type === 'getLogsForAI') {
 *     chrome.storage.session.get('debugLogs', (data) => {
 *       sendResponse({ logs: data.debugLogs?.slice(-100) || [] });
 *     });
 *     return true;
 *   }
 * });
 * ```
 * 
 * 然后在外部通过 Playwright 获取：
 * ```javascript
 * // 在 Playwright 中打开 Popup 页面
 * await page.goto('chrome-extension://YOUR_EXTENSION_ID/popup/index.html');
 * const logs = await page.evaluate(() => {
 *   return new Promise((resolve) => {
 *     chrome.runtime.sendMessage({ type: 'getLogsForAI' }, resolve);
 *   });
 * });
 * ```
