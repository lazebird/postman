# Mail Notifier 扩展隐私政策（Privacy Policy）

> 本隐私政策适用于浏览器扩展 **Mail Notifier**（MV3），用于 Chrome Web Store 与 Microsoft Edge Add-ons 商店上架时的「隐私权政策 URL」。
> 生效日期：以首次商店发布为准。本文件建议随版本在仓库内维护，并托管为**公开可访问的 https 页面**后再填入商店。

---

## 1. 简介

Mail Notifier 是一款邮件未读提醒扩展，支持 **163 / QQ / USTC / Gmail** 邮箱。
其设计核心为**纯本地处理、无服务器、自动运行完全静默**：扩展在您的本机浏览器中完成所有邮件状态检查与提醒，**不上传您的邮箱数据到任何第三方服务器**。

## 2. 我们收集哪些信息

扩展仅在您于**本机浏览器**登录上述邮箱并授权的情况下，读取完成邮件提醒所必需的**最小数据**：

- **邮箱账户的会话状态（sid）与未读计数**：用于向 webmail 查询是否有新邮件并展示角标 / 发送桌面通知；
- **Gmail 账户数据**：经隐藏 Atom feed（`mail.google.com/mail/u/0/feed/atom`）读取未读邮件元数据，依赖浏览器已登录 Gmail 的会话 Cookie，零 token；
- **浏览器 Cookies（会话 Cookie）**：仅用于向您已登录的 webmail 发出本机请求以获取未读数。

> 我们**不**读取、收集、存储您的邮件正文内容用于任何分析；仅使用未读元数据。

## 3. 数据如何存储与使用

- 所有数据（sid、未读状态、API 模式等）仅保存在您的本机浏览器 **`chrome.storage.local`** 中；
- 检查逻辑全部在本机 `Service Worker` 内执行；
- 我们**不拥有、不运营任何服务器**，数据**不传输、不共享、不出售、不用于广告或画像**。

## 4. 自动运行与隐私

- 定时自动检查在后台静默执行，**绝不自动打开新标签页、不常驻页面**；
- 仅当您在 Popup / 设置页**主动点击**时，才可能打开邮箱页以同步会话；
- 若后台无法取得数据，只会提示「需手动同步」，不会越权访问您的其他数据。

## 5. 第三方（Google）数据处理

- **Gmail** 通过隐藏 Atom feed 读取未读，依赖浏览器已登录 Gmail 的会话 Cookie，零 token、无需 Google Cloud OAuth 授权；
- Gmail 相关数据的处理遵循 **Google API 服务条款** 与 **Google 隐私政策**；
- 扩展不会将 Gmail 数据用于任何 Google 限制之外的目的。

## 6. 数据共享与披露

我们**不会**向任何第三方出售、出租或共享您的数据，**除非**：
- 为遵守法律 / 监管 / 司法要求而必须披露；
- 为保护我们的权利或防止滥用。

## 7. 数据保留与删除

- 扩展卸载后，其存储在您本机浏览器中的数据即随之清除；
- 您也可以随时在扩展的 Popup / 设置页手动清除缓存的会话数据。

## 8. 权限用途说明

| 权限 | 用途 |
|------|------|
| `cookies` | 向您已登录的 webmail 附加会话 Cookie 以查询未读数（仅本机） |
| `storage` | 本地保存 sid / 未读状态 / API 模式 |
| `alarms` | 定时后台静默检查新邮件 |
| `notifications` | 发送新邮件桌面通知 |
| `tabs` | 仅用于识别并复用您**已打开**的邮箱标签（绝不自动开标签） |
| ~~`identity`~~ | ~~Gmail OAuth2 授权（只读）~~ —— **已废弃，v1.0.2 移除**（Gmail 改走隐藏 Atom feed + 会话 Cookie，不再申请该权限） |
| `scripting` / `declarativeNetRequest` | 注入脚本 / 网络规则以支撑混合检查（详见说明） |

## 9. 安全

扩展使用 `chrome.storage.local` 在受隔离的浏览器扩展沙箱中保存数据，并遵循 MV3 最小权限原则。
因数据始终保存在本机，安全风险主要来自您本机环境本身。

## 10. 政策更新

本政策可能随功能演进更新。更新后将在扩展的商店列表说明中提示，重大变更会在新版本 release note 中说明。
