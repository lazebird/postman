# 浏览器邮箱插件（Edge Mail Notifier）

- Microsoft Edge 浏览器插件（MV3）
- 支持 163 / QQ / Gmail / USTC 等邮箱
- 支持邮件检查、未读计数、桌面通知、快速跳转邮件
- 混合方案：内容脚本提取会话 + SW 独立 API 检查

## 核心架构：混合检查模式

本项目采用「混合模式」实现**免常驻邮箱页**的后台未读检查：

```
┌─────────────────────────────────────────────────────────────────────┐
│                      v0.5.0 混合模式检查流程                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  用户偶尔打开邮箱页登录（可选，一次即可）                                  │
│       │                                                             │
│       ▼                                                             │
│  内容脚本注入 → 读取真实未读数 + 提取 sid → 缓存（12小时 TTL）               │
│       │                                                             │
│       ▼                                                             │
│  SW 定时（chrome.alarms）→ 调 API → 获取未读数                         │
│       │                                                             │
│       ├── ✅ 163：无 sid 也可直接通过 Cookie 调 API                     │
│       ├── ✅ QQ：有缓存 sid 时直接调 API                                │
│       ├── API成功 → 未读 badge + 桌面通知                              │
│       └── API失败（无 sid / 会话失效）                                 │
│             │                                                       │
│             └── 🔄 自动恢复：开后台标签 → 提取 sid → 关闭标签 → 重试       │
│                     └── 仍失败 → 提示用户手动登录邮箱                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 为什么需要「混合」而不是纯内容脚本？

| 方案 | 需常驻邮箱页 | 定时后台检查 | 可靠度 | 说明 |
|------|------------|------------|--------|------|
| **混合模式（当前）** | ❌（偶尔打开一次即可） | ✅ | ⭐⭐⭐ | 内容脚本提取 sid → SW 独立调 API |
| 纯内容脚本 | ✅ 需要 | 仅页面存活时 | ⭐⭐⭐⭐ | DOM 读取最可靠，但需常驻页面 |
| 纯 SW API | ❌ | ✅ | ⭐⭐ | 依赖 sid 有效性，sid 过期即失效 |

### 关键流程（授权 → 获取未读数）

1. **授权（一次）**：浏览器打开并登录 `mail.163.com` / `mail.qq.com`
2. **同步会话**：Options → 点「🔑 授权·同步163会话」→ 扩展打开邮箱页 → 内容脚本提取会话令牌 sid 并缓存 → 显示「已授权 ✅」
3. **获取未读数**：在邮箱中打开左侧「收件箱」主页面 → 点「📥 获取未读数·163」→ 读出未读数（与网页一致）
4. **日常使用**：SW 每 N 分钟用缓存 sid 调邮箱 API → 获取未读数 → badge + 通知
5. **sid 过期**（12 小时 TTL）：自动回退到内容脚本探测；若仍失败则提示重新授权

> **提示**：若「获取未读数」返回为空，多半是扩展落在了联系人等辅助页面——请确认当前停留的是邮箱「收件箱」主页面后再读取。

## 数据持久化与存储分层

| 存储区 | 存放的数据 | 插件更新时 |
|--------|-----------|-----------|
| `chrome.storage.local`（持久化） | 账号配置、用户设置、检查历史 | ✅ **保留** |
| `chrome.storage.session`（会话级） | sid 会话令牌（12小时TTL）、调试日志 | ⚠️ 清空，可重新同步 |
